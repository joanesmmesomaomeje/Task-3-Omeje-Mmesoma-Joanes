# Task-3-Omeje-Mmesoma-Joanes

## Project Title
SQL Analysis of an E-Commerce Orders Dataset

## Project Overview
This project uses T-SQL in SQL Server Management Studio (SSMS) to query and analyze an e-commerce orders dataset. The queries cover data retrieval, aggregation, and business metrics such as total orders, total revenue, and average order value.

## Objectives
- Retrieve and inspect order records
- Count total orders
- Calculate total revenue
- Calculate average order value
- Draw insights from the query results

## Tools Used
- SQL Server Management Studio (SSMS)
- T-SQL
